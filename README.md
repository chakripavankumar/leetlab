💻 LeetLab

LeetLab is a coding practice platform designed to provide a simple and efficient environment for solving programming problems, submitting solutions, and tracking progress.

It supports separate Admin and User roles, with features for problem management, code execution, submissions, and personalized problem playlists.

✨ Features

* 👤 Role-Based Access — Separate Admin and User experiences.
* 🛠️ Problem Management — Admins can create, update, delete, tag, and categorize coding problems.
* 🧑‍💻 Online Code Execution — Execute solutions in multiple programming languages using Judge0.
* 📊 Submission Tracking — Store submissions and provide execution results and feedback.
* 📚 Problem Playlists — Users can create and organize custom playlists based on their learning goals.
* 🔐 Authentication & Authorization — Secure registration, login, and role-based access control.
* 🎨 Responsive UI — Built with React, Tailwind CSS, and DaisyUI.

🛠️ Tech Stack

Frontend: React · Vite · JavaScript · Tailwind CSS · DaisyUI
State Management: Zustand
Forms & Validation: React Hook Form · Zod
Backend: Node.js · Express.js
Database: PostgreSQL · Prisma ORM
Code Execution: Judge0 API

🏗️ API Architecture

LeetLab follows a REST-based API architecture covering:

* Authentication — Registration, login, and role-based access.
* Problems — CRUD operations, tagging, and categorisation.
* Code Execution — Multi-language code execution through Judge0.
* Submissions — Submission history, execution results, and feedback.
* Playlists — Create and manage personalised problem collections.

🎯 Goal

LeetLab aims to provide a focused coding practice environment where developers can solve problems, experiment with different languages, and organize their learning journey in one place.
